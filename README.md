# Homebrew Tap for iXpat

[iXpat](https://knightynite.github.io/ixpat/) — free macOS menu bar app that gives the Microsoft Surface Mouse (2nd Edition) its haptics, an Action Ring, kinetic scrolling and force click.

## Install

```bash
brew install knightynite/ixpat/ixpat
```

## Update

```bash
brew upgrade ixpat
```

## Uninstall

```bash
brew uninstall ixpat
```
